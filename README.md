# 뿌요뿌요 (웹)

브라우저에서 하는 뿌요뿌요입니다. 1인용 연습, CPU 대전, 온라인 1:1 대전을 지원합니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 에 접속합니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

`public/index.html` 파일만 열어도 1인용 연습과 CPU 대전은 서버 없이 됩니다.

## 메뉴

| 메뉴 | 내용 |
|---|---|
| AI 대전 | 연습(혼자), CPU 쉬움·보통·어려움. 타일마다 내 전적이 표시됨 |
| 대전 | 빠른 매칭, 방 만들기, 방 참가(4자리 코드) |
| 내 정보 | 닉네임, 플레이 횟수·승률·플레이 시간, 난이도별·온라인 전적, 최고 기록, 최근 경기 12개 |

기록은 브라우저(`localStorage`)에 저장됩니다. 메뉴는 방향키로 이동하고 Enter로 고르며, Esc로 뒤로 갑니다.

## 뿌요뿌요 vs 테트리스

AI 대전과 대전 화면 위쪽에서 **내 스타일**(뿌요뿌요/테트리스)을 고릅니다. AI 대전에서는 **CPU 스타일**(뿌요뿌요/테트리스/랜덤)도 고를 수 있습니다. 온라인은 각자 고른 스타일로 만나므로 뿌요 vs 테트리스 대전이 됩니다.

원작(뿌요뿌요 테트리스) 자료를 기준으로 맞춘 규칙은 다음과 같습니다.

| 항목 | 내용 |
|---|---|
| 테트리스 필드 | 10×20(+숨김 2줄), SRS 회전·월킥, 7종 가방, 홀드, 다음 5개, 고스트, 하드드롭, 고정 지연 0.5초 |
| 테트리스 → 테트리스 | 2줄 1 · 3줄 2 · 테트리스 4 · T스핀 싱글 2/더블 4/트리플 6 · 퍼펙트 10 · B2B +1 · REN 보너스 |
| 테트리스 → 뿌요 | T스핀 더블 3 · 트리플 4 · 퍼펙트 6, REN 보너스 약화. 공격은 왼쪽 게이지에 모였다가 줄을 지우지 않는 블록을 놓을 때 방해뿌요로 변환(1→4, 2→5, 4→8, 10→28 …) |
| 뿌요 → 테트리스 | 연쇄 단계 점수(+이월)가 210·630·1050·1710·3500·7000·14000점에 닿으면 1~7줄. 연쇄가 끝나면 아래에서 구멍 한 칸짜리 줄로 한 번에 최대 7줄 |
| 상쇄 | 양쪽 모두 내 예고 공격을 먼저 상쇄하고 남은 만큼 보냄 |
| 테트리스 CPU | 이동·회전(킥 포함)·내리기를 모두 탐색해 밀어 넣는 자리까지 찾음. 보통은 가끔, 어려움은 T스핀 더블 자리를 직접 만들고 T를 홀드에 아껴 두며 다음 조각까지 내다봄 |

참고: TetrisWiki·Hard Drop Wiki의 Puyo Puyo Tetris 문서, four.lol, 「ぷよテトおじゃま算」. 테트리스 쪽 마진 타임 배율은 원작 수치를 찾지 못해 16초마다 +25%(최대 3배)로 정했습니다.

## 대전 규칙 추가 사항

- **마진 타임**: 대전 시작 96초 후(일시정지한 시간은 빼고)부터 16초마다 공격력이 오릅니다. 뿌요는 목표 점수가 70→52→35…로 줄고, 테트리스는 보내는 양에 배율이 붙습니다. 가운데에 현재 배율이 표시됩니다.
- **전멸 보너스**: 판을 전부 지우면 다음 연쇄 첫 단계에 방해뿌요 30개가 추가됩니다(테트리스 상대는 2100점 추가). 대기 중이면 필드에 '전멸 보너스'가 표시됩니다.
- **위험 경고**: 테트리스 상대의 공격 게이지가 11칸 이상이면 뿌요 쪽에 '위험!'이 깜빡입니다.
- **큰 방해 아이콘**: 별 180, 달 360, 왕관 720, 혜성 1440 단위가 있습니다.
- **퀵턴**: 뿌요의 양옆이 막혔을 때 회전을 두 번 빠르게 누르면 180도로 뒤집힙니다.
- **판 크기**: AI 대전·대전 화면 위쪽에서 **넓게 8×14**(기본), **원작 6×12**, **타이니 12×24**(작은 뿌요로 넓고 높은 판, 방해뿌요가 한 번에 60개까지)를 고릅니다. 원작 판은 3열 맨 위가 막히면 끝납니다. 온라인은 방을 만든 사람의 판 크기를 따르고, 빠른 매칭은 같은 판 크기끼리 이어집니다.
- **선승제**: AI 대전·로컬 대전에서 1판 / 2선승 / 3선승을 고릅니다. 판이 끝나면 3초 뒤 다음 판이 자동으로 시작됩니다. 온라인은 같은 상대와의 누적 전적이 표시됩니다.

## 피버 규칙 · 엔드리스 피버

AI 대전·대전 화면 위쪽 **규칙**에서 통상/피버/빅뱅/스왑/파티/퓨전을 고릅니다(피버는 뿌요뿌요에만 적용, 온라인은 방을 만든 사람의 규칙).

- 상쇄할 때마다(연쇄 한 번에 한 칸) 점수판 아래 **피버 게이지**가 찹니다. 7칸이 차면 다음 조각부터 **피버**가 시작됩니다.
- 피버 중에는 내 판을 잠시 맡겨 두고 **연쇄 씨앗판**이 떨어집니다. 트리거 색이 든 조각이 바로 나오니 알맞은 자리에 놓아 터뜨리면 됩니다.
- 씨앗판을 끝까지 터뜨리면 다음 판이 한 연쇄 길어지고, 못 하면 짧아집니다. 연쇄 수 × 0.3초가 늘어납니다.
- 피버 시간(15초)이 끝나면 원래 판으로 돌아오고, 그동안 쌓인 방해뿌요가 떨어집니다. 피버 연쇄는 별도 점수표라 긴 연쇄의 공격력이 완만합니다. 씨앗판을 다 터뜨려도 전멸 보너스는 없습니다.
- 씨앗판은 매번 새로 만듭니다(마지막 연쇄부터 거꾸로 그룹을 끼워 넣고 시뮬레이션으로 연쇄 수를 확인).
- **엔드리스 피버**(AI 대전 → 연습, 뿌요뿌요): 피버만 계속하는 연습입니다. 30초에서 시작하고 연쇄 수 × 0.6초씩 늘어납니다. 시간은 연쇄 연출 중에도 흐르고 씨앗판이 떨어지는 동안만 멈춥니다.

## 빅뱅

**규칙 → 빅뱅**을 고르면 방해 공격 없이 라운드마다 모든 플레이어가 같은 퍼즐을 동시에 풉니다(뿌요뿌요·테트리스 모두).

- 뿌요뿌요: 연쇄 씨앗판(트리거 색 조각이 바로 나옴). 테트리스: 정해진 순서의 조각을 넣어 줄을 모두 채우는 퍼즐(다음 칸에 순서가 보이고, 홀드는 안 됨).
- 완성도(터뜨린 연쇄 ÷ 씨앗판 연쇄, 지운 줄 ÷ 퍼즐 줄)가 가장 높은 사람이 라운드 승리. 같으면 먼저 끝낸 사람(뿌요는 트리거를 놓은 시각 기준)이 이깁니다.
- 나머지는 `15 + 25 × 완성도 차이 + 2 × 라운드`만큼 체력(100)이 깎이고, 0이 되면 탈락합니다. 라운드 제한 시간은 20초이고, 라운드마다 퍼즐이 조금씩 커집니다.
- 온라인·리플레이에서는 각자 결과를 알리고 모든 결과가 모이면 모두 같은 계산으로 체력을 깎습니다.

## 스왑

**규칙 → 스왑**을 고르면 플레이어마다 뿌요뿌요 판과 테트리스 판을 둘 다 가지고 시작합니다(처음엔 고른 스타일).

- 25초가 지나면 다음 조각을 받을 때 다른 판으로 바뀝니다(연쇄·줄 지우기 도중에는 안 바뀜). 이름표 오른쪽에 남은 시간이 보입니다.
- 쉬는 판은 그대로 멈춰 있다가 다시 돌아오면 이어서 합니다. 쌓인 방해는 바뀐 판의 단위로 바뀌어 넘어가고, 점수는 이어집니다.
- 어느 판이든 꼭대기까지 차면 탈락합니다.

## 파티

**규칙 → 파티**: 2분 동안 점수로 겨룹니다. 꼭대기까지 차도 탈락하지 않고 판이 비워지며 점수가 15% 깎입니다.

- 6조각마다 조각에 **★아이템**이 붙어 나옵니다. 뿌요는 그 뿌요를 터뜨리면, 테트리스는 그 칸이 있는 줄을 지우면 발동합니다.

| 아이템 | 효과 |
|---|---|
| 방해 폭탄 | 상대 모두에게 방해(뿌요 12개 / 테트리스 3줄) |
| 판 정리 | 내 판 아래 3줄을 없앰 |
| 조작 반전 | 상대 좌우 조작이 8초간 반대(CPU는 느려짐) |
| 미리보기 가리기 | 상대 '다음'이 8초간 가려짐 |
| 속도 업 | 상대 낙하 속도 8초간 3배 |
| 점수 2배 | 10초간 내 점수 2배 |

- 걸린 효과는 판 위쪽에 남은 시간과 함께 보입니다. 시간이 끝나면 점수 순으로 순위가 정해집니다.

## 퓨전

**규칙 → 퓨전**: 스타일과 상관없이 모두 폭 10의 퓨전 판 하나로 겨룹니다. 뿌요 쌍과 테트리미노가 섞여서 나옵니다(순서는 모두 같음, 홀드 없음).

- 테트리미노는 뿌요를 뚫고 떨어지고, 놓이면 겹친 뿌요는 그 위로 밀려 올라갑니다. 뿌요는 무엇에든 닿으면 멈추고 아래가 비면 떨어집니다.
- 한 줄이 블록·뿌요로 가득 차면 지워집니다. 방해뿌요가 섞인 줄은 지워지지 않으니 옆 뿌요를 터뜨려 없애야 합니다.
- 같은 색 뿌요 4개 이상이 이어지면 터집니다. 줄 지우기와 뿌요 터뜨리기는 연쇄로 이어지며 둘 다 방해뿌요 공격이 됩니다.

## 3~4인 대전

- AI 대전·대전 화면 위쪽 **인원**에서 2인/3인/4인을 고릅니다. 3~4인은 한 판 승부이고, 마지막까지 살아남은 사람이 승리합니다.
- **공격 대상**: 나를 마지막으로 공격한 사람에게 반격하고, 없으면 점수가 가장 높은 사람을 노립니다. 가운데 패널에 지금 공격 대상이 표시됩니다. 테트리스는 뿌요 상대에게 게이지를 모으는 동안 그 뿌요 상대를 계속 노립니다.
- **AI 대전**: 나머지 자리는 CPU(스타일은 CPU 설정, 랜덤이면 CPU마다 따로)로 채웁니다. 내가 탈락하면 판이 끝나고 남은 CPU는 점수 순으로 순위를 매깁니다.
- **로컬 대전**: 1P·2P 외 빈자리는 CPU가 채웁니다.
- **온라인**: 방 만들기·빠른 매칭 모두 고른 인원이 모이면 시작합니다(빠른 매칭은 같은 판 크기·인원끼리). 내가 탈락해도 끝까지 관전하고, 게임 중 나간 사람은 탈락 처리됩니다.

## 리플레이

- 끝난 판은 자동으로 녹화되어 **내 정보 → 최근 경기**에 ▶(다시 보기)·⤓(파일로 저장) 버튼이 생깁니다. 최근 12판까지 브라우저에 저장되고, 저장 공간이 모자라면 오래된 것부터 지워집니다.
- **리플레이 불러오기**로 저장해 둔 파일(`.json`)을 열어 볼 수 있습니다.
- 재생 중 `← →`로 배속(×0.5 · ×1 · ×2 · ×4), `Esc`로 일시정지합니다.
- 온라인 대전도 상대 판까지 함께 녹화됩니다.

## 설정 (오른쪽 위 ⚙)

- 배경음악·효과음 볼륨. 배경음악은 메뉴와 게임에서 다르게 나오고, 마진 타임이 되면 빨라집니다.
- 키 설정: 동작마다 키를 2개까지 지정할 수 있습니다.
- 게임패드: 십자키 이동(↑ 하드드롭), A 시계 회전, B 반시계 회전, X/LB 홀드, Start 일시정지. 메뉴도 패드로 움직일 수 있습니다.

로컬 대전 조작은 1P가 `WASD`(W 하드드롭) · `Q/E` 회전 · `R` 홀드, 2P가 `방향키`(↑ 하드드롭) · `. /` 회전 · `,` 홀드입니다.

## 온라인 대전

1. 메인 메뉴에서 **대전**을 누릅니다. 서버 주소는 접속한 주소로 자동 입력됩니다.
2. 둘 중 하나를 고릅니다.
   - **빠른 매칭**: 먼저 기다리던 사람과 바로 이어집니다.
   - **방 만들기**: 4자리 방 코드가 나오면 상대에게 알려주고, 상대는 코드를 넣고 **참가**를 누릅니다.
3. 끝나면 두 사람 모두 **다시 하기**를 누르면 새 판이 시작됩니다.

### 같은 네트워크
서버를 켜면 콘솔과 대전 메뉴에 `http://192.168.x.x:3000` 같은 주소가 나옵니다. 같은 와이파이·공유기에 있는 사람은 이 주소로 접속하면 됩니다.

### 게임 중 나가기
Esc(모바일은 Ⅱ 버튼)를 누르면 연습·AI 대전은 일시정지되고, 계속하기 / 처음부터 / 메뉴로 나가기를 고를 수 있습니다. 온라인 대전은 멈추지 않고 '기권하고 나가기' 확인 창이 뜹니다. 기권하면 패배로 기록됩니다.

| `public/js/play.js` | 결과 창, 이펙트, 게임 진행, 그리기 |
| `public/js/input.js` · `net.js` · `main.js` | 입력, 온라인 클라이언트, 시작 |
| `public/js/replay.js` | 이벤트 버스(온라인 전송·녹화), 리플레이 저장·재생 |
| `tests/smoke.js` | `npm test` — 여러 모드를 CPU끼리 돌려 오류 확인 |
| `tests/online.js` | `node tests/online.js 3` — 브라우저 여러 개로 온라인 N인 대전 확인 |

스크립트는 모듈이 아닌 일반 `<script>`라서 `index.html`을 파일로 바로 열어도 동작합니다.

온라인 대전은 각자 자기 필드를 직접 계산하고, 서버는 메시지에 보낸 사람의 자리 번호를 붙여 다른 사람들에게 넘겨주기만 합니다.

- 두 사람은 서버가 정한 같은 시드로 같은 뿌요 순서를 받습니다.
- 뿌요를 놓을 때(`lock`)와 방해뿌요가 떨어질 때(`garb`) 이벤트를 보냅니다. 상대 화면에서는 같은 규칙으로 이를 재생하므로 연쇄·출렁임 애니메이션이 그대로 보입니다. 이벤트마다 격자 스냅샷도 함께 보내서, 어긋나면 바로 맞춥니다.
- 떨어지는 조각의 위치, 점수, 쌓인 방해뿌요 수는 초당 20번 보냅니다.
- 공격은 연쇄 단계마다 `atk`, 상쇄는 `off` 메시지로 보냅니다. 받는 쪽에서 구슬이 도착할 때 방해뿌요가 쌓입니다.
